# 📊 BlinkIT Grocery Power BI Dashboard

Welcome to the **BlinkIT Grocery Power BI Dashboard** repository! This project provides insights into grocery sales data using interactive visualizations built with Power BI.

---

## 🔍 Project Overview

This dashboard analyzes grocery sales data to uncover trends, patterns, and key performance indicators (KPIs). It assists stakeholders in making informed decisions by presenting data in an accessible and interactive format.

---

## ✨ Features

- Interactive filters and slicers for dynamic data exploration
- Time-series visualizations to track sales over periods
- KPIs highlighting crucial metrics
- Drill-down capabilities for detailed analysis
- Clean and professional layout for easy interpretation
